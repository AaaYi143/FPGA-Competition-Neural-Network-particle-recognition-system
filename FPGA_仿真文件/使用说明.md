# 比赛视频仿真波形

这组仿真基于当前登记的512点平均、四类别FPGA工程，不改变可综合RTL、模型或BIT。输入类别为小米、珍珠粉、细盐、白砂糖。文案中的玻璃微珠尚无本工程的对应权重与数据，未模拟为已能识别。

## 打开已生成的波形

双击 `Open_Powerup.cmd` 看上电初始化；双击 `Open_Pouring.cmd` 看四类依次进入与离开。打开后点 Zoom Fit，放大下表区间。WDB是本次实际RTL仿真生成的数据，WCFG保存了便于讲解的信号列表。

|画面|建议查看的时间区间|
|---|---|
|上电复位|powerup：0～500ns|
|通道时序扫描|powerup：500ns～40µs|
|工作中再次复位|powerup：41.0～41.5µs|
|小米进入、识别、离开|pouring：30～274µs|
|珍珠粉进入、识别、离开|pouring：243～486µs|
|细盐进入、识别、离开|pouring：455～698µs|
|白砂糖进入、识别、离开|pouring：668～911µs|

scene：0空载、1小米、2珍珠粉、3细盐、4白砂糖。result_class是从0开始的网络类别：0小米、1珍珠粉、2细盐、3白砂糖；必须在result_valid有效时读取，并同时检查result_empty。空载时class值不代表颗粒存在。

raw/valid：平均后的31维特征依次输入；feature_index标识特征位置。preproc_out_0_255/preproc_valid显示归一化输出。done_fc1/2/3显示各层计算完成。result_valid显示分类完成；display_code为屏幕编号1～4，空载为0、数码管显示横线。

## 仿真覆盖与边界

- powerup实例化实际Main，使用仿真专用XADC stub。检查32路计数、累加、均值、输出清零，串口结果线空闲；再注入数字EOC事件，产生34次取样并验证再次复位清零。
- pouring实例化实际Neural_network，回放已有验证集各类最前面的5帧（按原验证集次序，未按预测是否正确筛选），中间插入零输入空载。共30帧、930个特征；逐项核对归一化、三层全连接、两层激活与分类结果。
- 空载使用合成零向量。颗粒帧是先前采集并已完成平均的数据，来源与期望结果见replay_manifest.json。
- 这不是模拟激光、颗粒运动、模拟运放建立过程或ADC真实上电校准。数据帧间的演示间隔是测试平台安排，不能作为撒料速度、整机响应时间或推理性能测量。
- 当前神经网络仅用采集槽0～30的31维输入；不能在视频中把该波形说成32维全部进入模型。
- 上电测试展示的是数字逻辑在外部复位下的初始化，不验证Flash启动、PLL锁定或电源时序。

## 重跑

工作区根目录运行：

```
python scripts/prepare_video_simulation.py
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Run_Video_Simulation.ps1
```

使用现有Windows Python；prepare会复制当前登记RTL与固定旧验证数据，检查数据身份。若切换为新模型，需重新生成配套参考结果，不应沿用旧期望值。

powerup_simulation.log应包含POWERUP_ALL_PASS；pouring_simulation.log应包含POURING_ALL_PASS和errors=0。
