## Python 分析

使用本机bundled Python与NumPy，执行 `-m unittest discover -s tests -v`，**11项测试全部通过**，含：

- 暗场/增益校正和负值裁剪、空数据/通道数/非法校准。
- 中心通道排除或全部32散射通道、零光时不提供有效粒径。
- 已知代数解、正则化和非负边界、体积CDF分位数。
- 12组随机小问题与穷举全部活动子集的独立最优值对照。
- 非法光学核、64位时间戳保存、demo CLI。
- 仅在明确ADC最大码时检查饱和，区分中心饱和和散射饱和。

已运行20帧合成示例，输出在 `build/demo/SYNTHETIC_demo_corrected.csv` 与 `build/demo/SYNTHETIC_demo_summary.json`。示例没有物理核或粒径输出；不能将其作为比赛实测数据。

## 速率预算检查

执行 `tools/rate_budget.py --adc-sps 1000000 --settle-us 1`，按默认其余假设得到每路3.34μs、输出停顿前约9356.29帧/秒；10000帧/秒所需每路预算3.125μs，因此余量不足。88字节应用帧对应UART 8N1至少8.8Mbaud。数字均为明确假设的计算结果。
